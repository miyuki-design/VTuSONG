# VTuSONG 歌詞とメロディー一致 v3

- `worker/index.js`: Cloudflare Workerに貼り付け→Deploy。AIが各音符に `lyric` を付け、小節歌詞を実際の音符の歌詞から再構成します。新規生成時から必ず両者が一致します。
- `src/App.tsx`、`src/types.ts`、`src/style.css`: GitHubの同じパスに上書き→GitHub Actionsから新規TestFlightビルド。再生時に**音符単位**で歌詞を光らせます。
- 旧楽曲は従来通り再生・表示できますが、音符ごとの割り付けがないため小節単位で表示。手動で歌詞だけ書き換えた小節も割り付けを無効化します。
- 従来のオフボーカル書き出し、伴奏、VTuREC連携、Apple署名設定は変更していません。
- AIのStructured Outputsのスキーマが変わるため、Workerのデプロイとアプリの更新を両方行ってください。
- 歌詞と音符の一致は**テキストの譜割り対応**です。音声で歌う仮歌や発音の自然さは別途実装・実機検証が必要です。
- AIが音符単位の指定を満たせない場合、生成は失敗することがあります。
