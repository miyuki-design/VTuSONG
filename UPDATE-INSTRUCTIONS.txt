GitHubの VTuSONG リポジトリ > Add file > Upload files から、ZIP展開後の「src」フォルダ内3ファイルを上書きしてください。
GitHub Webではフォルダ階層に注意。確実な方法は各ファイルを個別に開いて、編集画面で内容を丸ごと置き換えることです。
変更後、Actions > VTuSONG iOS to TestFlight > Run workflow から新規ビルドしてください。
Apple署名・Cloudflare Worker・GitHub Secrets/Variablesは変更不要です。

内容:
- 試聴モード「メロディーのみ」追加
- 再生時計と同期して歌詞を小節単位で強調表示
- ジャンル別ドラム・ベース・ピアノ・ギターのリズム差分
- ピアノ・ギターを加算合成の減衰音へ変更（電子音感を軽減）
- Aメロとサビで伴奏の強弱を変化

限界:
- ピアノ・ギターは楽器サンプルではないため、実録音のような生音ではありません。
- 歌詞は小節単位同期のみ。単語/モーラの正確な同期にはAI生成の音符対応付けが必要です。
- 実機でのビルド・音質評価は未実施です。
- 既存のAI曲の読み込み、WAV書き出しは既存仕様を保持。
- ZIPには上記3ファイルだけが含まれます。既存のTestFlightワークフローは絶対に上書きしないでください。
